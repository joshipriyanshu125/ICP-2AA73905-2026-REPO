## Selected Projects

### Project 1: Task Management Application (Project 2)

- **Real-World Problem:** Teams and individuals need an organized system to track tasks, deadlines, and productivity.
- **Difficulty Level:** Beginner to Intermediate
- **Key Skills & Tools:** React.js / Modern JS, State Management, LocalStorage, CRUD Operations, CSS Grid/Flexbox.
- **Expected Outcome:** Functional task manager with full CRUD operations, filtering, search, and local persistence.
- **Planned Features & Milestones:**
  - **Week 2:** UI layout, Task Creation Form, Priority & Tag selection.
  - **Week 3:** CRUD operations, state management, LocalStorage integration.
  - **Week 4:** Status filtering (All, Active, Completed), search bar, and UI polish.

### Project 2: Weather Dashboard Application (Project 6)

- **Real-World Problem:** Users need quick access to real-time weather forecasts and visual climate data for daily planning.
- **Difficulty Level:** Beginner to Intermediate
- **Key Skills & Tools:** OpenWeatherMap API, Geolocation API, Data Visualization, Async/Await, Responsive Design.
- **Expected Outcome:** Interactive dashboard showing current weather, 5-day forecasts, geolocation data, and search history.
- **Planned Features & Milestones:**
  - **Week 4:** OpenWeatherMap API integration, city search, current weather card.
  - **Week 5:** 5-day forecast display, Geolocation integration, error handling.
  - **Week 6:** Data visualization charts, temperature unit toggle, favorite cities storage.
